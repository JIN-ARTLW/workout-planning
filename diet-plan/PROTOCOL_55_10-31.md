## 🎯 목표 55.9 유지 확정 (8/31 재산출 — 본인 지시)

> **코치 정정:** 같은 날 "55.9 도달 불가·57.5로 재설정"이라 판정했으나 **갭을 정밀 계산한 결과 과대평가였음.** 아래가 정확한 값.

```
필요:  73.5 → 55.9 = 17.6kg / 8.71주 = 주 2.02kg

기본 프로그램 최대치   -15.25kg  → 58.25
+ 상환 사이클 45분     -1.79kg   → 56.46
────────────────────────────────────────
55.9까지의 갭:  0.56kg = 3,388kcal = 하루 56kcal   ← 사이클 10분
```

**"불가능"이 아니라 "여유가 0"이 정확한 표현.** → **10/18 58.6 / 10/31 55.9 유지.**

### 달성 조건 3개
```
1️⃣ 61일 이탈 0            ← 실제 병목
2️⃣ 평일 상환 사이클 45분  (비협상)
3️⃣ 매일 +10분 추가        (사이클 55분 or 저녁 걷기 15분)
```
> 생리학적으로는 가능. **병목은 전부 실행.** 여유가 0이므로 하루라도 0이 나오면 넘길 곳이 없다.

### 확률
```
10/31 55.9  →  20~25%
```
> 낮은 이유는 신체가 아니라 **9일 중 0일이라는 실행 기록.** 3일 연속 완수 시 ~35%, 7일 연속 시 ~45%로 회복.

### ⚠️ "개강하면 잘할 수 있다"에 대한 코치 판정

**개강은 조건이 개선되는 이벤트가 아니라 악화되는 이벤트다.** 하루가 통째로 비어 있는 상태에서도 미실행 → 9/1부터는 월~목 학교 + 토~일 알바로 **가용 시간이 절반**. "조건이 갖춰지면 하겠다"는 접근은 성립하지 않는다.

### 🪜 진입 장벽 최소화 (8/31 결정)
> **9일 연속 0인 상태에서 A안을 요구하는 것은 10번째 실패를 설계하는 것.**


**필요한 것은 완벽한 하루가 아니라 연속된 3일.**

```
→ 러닝 1~2시간 전 또는 직후에 배치
```
> ⚠️ 정강이 압통은 **W5~W7(주 61~80km)** 구간에 발생 확률이 가장 높다. 이 시기 중단 기준을 특히 주시.

### 🎯 1000km는 폐기가 아니라 시간축 확장
```
10/18까지        ~296km
```

> 🏈 **국대 관점에서도 이 배합이 맞다.** 플래그풋볼은 마라톤이 아니라 **가속·컷** 종목 — 주 90km 러닝은 오히려 스프린트 파워를 깎는다. **300km + 풋워크 + 웨이트**가 종목 적합 배합.

### 👟 신발 교체 주기 — 정정
```

```
**본인의 "1000km마다 교체"는 늦은 편.** 겉은 멀쩡한데 지지 기능이 사라진 신발 = 발목·족저근막 부상의 흔한 원인.

> ⚠️ **원칙: 신발 수명을 목표로 삼으면 몸이 먼저 소모된다.**

### 🚨 중단 기준 (비협상 — 볼륨 상향 시 항상 적용)

1. **정강이 앞쪽 한 점을 누르면 아픔** ← 피로골절 전조. **가장 위험.** "뛸 땐 괜찮은데 누르면 아픈" 형태로 옴

## 📋 일일 보고 의무 (8/28 신설)

> **사유: 8/21~8/27 7일간 시작일이 7회 이동, 5일 손실.** 「0인 날 금지」 규칙을 만든 다음 날에도 0이 발생 → 규칙만으로는 부족, **보고 의무로 강제.**

**매일 21시, 한 줄:**
```
오늘 A / B / C 중 [  ] · 누적 [  ]km
```
- 못 했으면 못 했다고 보낸다. **미보고 = 0으로 기록.**
