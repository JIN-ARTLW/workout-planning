# 🏋️ 주간 트레이닝 스플릿 (애슬레틱/기능성 + 데피·복근)

> 목표: 하체·엉덩이 라인(59바지) + 복근 + 애슬레틱 파워. 러닝: `RUNNING_10-18.md`.
> 헬스 5(월~금) + 집 1(토) + 일 완전휴식 / 러닝 주6(월~토 아침 이지, 일 X).
> ⚠️ **평발+왼발목 이력+감량기** → 플라이오 저~중충격·착지 통제(본격 고강도는 9월). 볼륨 많음 → **floor·단백질·수면이 전제**(굶으면 이 볼륨=부상·정체).

## 📅 주간표
| 요일 | 장소 | 루틴 |
|---|---|---|
| 월 | 헬스 | 하체 + 플라이오 |
| 화 | 헬스 | 상체 + 복근(앞) + 상체 플라이오 |
| 수 | 헬스 | 전신협응 + 복근(심부/회전) |
| 목 | 헬스 | 하체 + 플라이오 (월과 동일) |

- 부위 빈도: 하체 3(월목토)·상체 3(화금토)·전신 1(수)·복근 3(화수금)·플라이오 3(하체날)
- 모든 저항 **2RIR**(실패 금지). 플라이오 **착지 사뿐히("쿵" X), 내려올 땐 스텝다운.**

## 🦵 하체 (월·목) — 머신 → 플라이오
**머신(컴파운드→고립, 2RIR):**
1. 시티드 레그프레스 15×4
2. 힙쓰러스트 15×3 (엉덩이 라인)
3. 라잉 레그컬 15×4
4. 레그 익스텐션 15×4
5. 힙 어덕션 15×4 / 힙 어브덕션 15×4
6. 이심성 카프레이즈(하강 3초, 피라미드) 15×4 (평발 강화)
7. (여력) 런지 좌우 12×3

**플라이오(스텝박스, 머신 후·저볼륨):**
- 스텝업(파워, 니업) 좌우 10×3 / 박스 스쿼트점프(스텝다운 착지) 8×3 / 스텝업 점프 좌우 8×3 / 레터럴 스텝오버 좌우 12×3 / 박스 카프레이즈 15×3
- (여력 바닥) 스쿼트점프 8×2·스케이터 좌우 10×2

## 💪 상체 (화·금) — 근력 → 상체 플라이오 → 복근
**웜업:** 밴드 외회전 2×15 / 페이스풀 2×15 / Y-T-W (부상예방)
**근력(당기기·밀기 균형, 2RIR):**
1. 랫풀다운 15×4
2. 시티드 로우 15×4
3. 체스트프레스/벤치(빈봉→점진↑) 10×3~4
4. 숄더프레스 (↔해머컬 슈퍼세트 가능) 10×4
5. 이두: 암컬머신/덤벨 15×3~4 (팔 거의 다 펴기→수축)
6. 삼두: 이지바 라잉 트라이셉스 15×4 (or 딥스 어시스트)
7. 전완 15×4
**상체 플라이오(파워, 1~2개):** 플라이오 푸시업(무릎 시작 OK) 6×3 / 메디신볼 체스트패스·슬램 8×3

## 🔥 전신협응 + 복근 (수) — 파워데이
- 케틀벨 스윙 15×4 (힙 파워·저충격) / 케틀벨 or 덤벨 클린 8×3
- 스텝업(무게) 좌우 10×3 / 파머스워크 30m×3
- 메디신볼 슬램 10×3 / 배틀로프 or 로잉 30초×4 (컨디셔닝·저충격)

## 🎯 복근 (화·수·금 3분할)
- **화(앞):** 행잉/라잉 레그레이즈 15×3 · 케이블/밴드 크런치 15×3
- **수(심부·회전):** 플랭크 45초×3 · 데드버그 12×3 · 케이블 우드촙 12×3 · 팔로프 프레스(항회전) 12×3
- **금(옆·라인):** 사이드플랭크 좌우 40초×2 · 러시안 트위스트 20×3 · 할로우홀드 30초×3
> 복근 데피는 **체지방↓이 8할.** 운동=근육, 선명함=감량. 병행이 정답.

## 🏠 토 — 홈트 상하체 통합 + 플라이오 (층간소음 OK)
- **하체:** 맨몸 스쿼트 20×3 · 리버스 런지 좌우 12×3 · 힙쓰러스트(바닥) 20×3 · 카프레이즈 20×3
- **하체 플라이오:** 스쿼트점프 8×3 · 점프런지 좌우 8×3 · 스케이터 좌우 10×3 · 브로드점프 6×3
- **상체:** 푸시업 12×3 · 파이크푸시업 8×3 · 타월/책상 로우 12×3 · 딥스(의자) 12×3 · 플라이오 푸시업 6×2
- **복근:** 플랭크+사이드플랭크+데드버그 순환
→ 강도 적당히(헬스 못 가는 날 유지용).

## 🚦 플라이오 안전 (비협상)
1. **착지가 전부** — 앞꿈치→발전체, 무릎·엉덩이로 흡수. "쿵" 금지. **내려올 땐 점프 X, 스텝다운.**
2. **질>양** — 세트당 6~10, 힘 있을 때만. 지치면 중단(부상=지친 착지).
3. **하체날만**(월목토), 상체·러닝날 X → 발목 회복.
4. **아침 발바닥 통증·발목 붓기 = 즉시 플라이오 중단**, 머신·워크만.
5. **고강도(높은박스·뎁스점프·연속바운딩·배구점프) = 9월(유지기·회복 후).**

## ⚠️ 회복 (이 볼륨 감당 조건)
- floor·단백질(근손실 방어)·수면 7h 못 채우면 **부상·정체.** 굶으면 이 스케줄이 독.
- 일요일 완전휴식 = 몸 리셋, 다음주 질↑. 통증·2주 연속 중량저하 = 볼륨↓.

> ※ 플라이오 세부는 영상 참고 후 추가·조정 예정(본인).
