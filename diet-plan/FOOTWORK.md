# ⚡ 풋워크 루틴 (배구 + 플래그풋볼)

> 장소 2곳:
> - **A. 인조잔디 축구장**(넓음) — 터프화/스터드, 풀버전 가능.
> - **B. 공원 우레탄(놀이터 옆, 좁음)** — **일반 운동화**(스터드 X: 우레탄에선 접지 과해 발목 꺾임 위험). 충격흡수는 잔디보다 좋아 평발·발목엔 유리. **긴 직선 드릴 불가 → 좁은 공간판 사용(아래).**
> 장비: **콘 4색(다수)·래더·밴드(스프린트용)·테니스공.** (미식볼=여기선 패스)
> ⚠️ 평발·오버프로네이션·왼발목 이력 → 착지 사뿐히, 컷 시 무릎 안쪽 무너짐 금지(발 바깥날로 딛고 밀기).

## 🎯 원칙 (짧은 기간에 늘리는 법)
- 풋워크·민첩성 = **신경 적응이 8할.** 같은 것만 반복 → 2~3주 정체. **고정 뼈대 + 초점 로테이션**이 정답.
- **플래그 = 탑스피드 아니라 "첫 3스텝 가속 + 컷"이 결정적.** (본인 약점=순발력/가속 → 밴드·가속 드릴로 정조준. 감량되면 가속 체감 확↑)
- **매주 진행:** 같은 드릴도 ①속도↑ ②거리↑ ③반응요소 추가(신호 보고 출발) 순으로 난도 올림. ← 이게 진짜 레버.

## 🧱 매일 고정 (뼈대 ~10분)
- **예열:** 고관절 왕복 1바퀴 + 왕복 조깅 1바퀴 + A-스킵 20m×2 + 하이니 20m×2
- **래더:** 잔발(퀵피트) 왕복 · 인-인-아웃-아웃 · 래터럴 사이드스텝 · 아이키셔플 (각 2회, 빠르게>크게)

## 🔄 초점 로테이션 (요일별 ~20분)

### 컷·방향전환 데이 (플래그) — 월·목
- **밴드 저항 스프린트** 10m×6 (기둥/파트너 저항, 첫 스텝 폭발)
- **밴드 저항 첫스텝** 45도 기울여 출발 ×6
- **5-10-5(프로 어질리티):** 중앙→5야드→10야드 반대→5야드 ×4~5 (컷 시 발 바깥날)
- **T-드릴 / 박스드릴:** 콘 배치, 전진→셔플→백페달 ×3
- **셔플→스프린트 전환:** 사이드셔플 5m→신호에 앞으로 튀기 ×5

### 점프·어프로치 데이 (배구) — 화·금
- **어프로치 스텝**(좌-우-양발) 무점프 리듬 10회 → 낮은 점프+사뿐 착지 8×2
- **블로킹 점프**(제자리 두 손 위로) 8×2 (하나씩 착지 확인)
- **골대기둥 터치 점프** 6×2 (내려올 때 무릎·엉덩이 흡수, "쿵" 금지)
- ⚠️ 러닝·상체 많이 한 날엔 점프 볼륨↓

### 반응·복합 데이 — 수·토
- **콘 컬러 리액션:** 4색 사방 배치 → 색 신호에 그쪽 대시→터치→복귀 ×8~10 (플래그+배구 반응)
- **테니스공 드롭-캐치:** 팔 벌려 떨구고 2바운드 전 잡기 (순반응)
- **테니스공 벽 던져 좌우 랜덤 받기** (배구 리시브 반응)
- **미러 드릴/지그재그** 콘 랜덤

## 🅱️ 좁은 공간판 (공원 우레탄 — 긴 직선 불가 시 대체)
> 5-10-5(≈9m)·밴드 스프린트 10m 불가 → **짧은 거리·제자리 저항**으로 가속 자극 유지.
- **월 드라이브 15초×4** — 벽/기둥 손 짚고 몸 45도 기울여 무릎 번갈아 강하게 드라이브. **공간 0, 좁은 데선 밴드 스프린트 대체 1순위**(가속 자세·힘).
- **밴드 저항 첫스텝 3~5m ×6** — 첫 3스텝만 폭발. 짧아서 OK. 세트간 완전회복.
- **밴드 제자리 드라이브 15초×3** — 저항 이기며 제자리 하이니(전진 X).
- **컷: 3-5-3 축소판(콘 간격 3m) ×4** or **박스 셔플**(콘 4개 2×2m: 전진→셔플→백페달→셔플) ×4.
- **테니스공 드롭-캐치** — 공간 0, 순반응.
- ⚠️ 놀이터 옆 = 사람·아이 동선 확인. 밴드는 **튼튼한 기둥에만** 고정(놀이기구 X).

## 🧊 마무리 (2~3분)
- 발목 서클, 종아리 흔들기, 소레우스·족저근막 가볍게
- (밴드 래터럴 워크 옵션 — 엉덩이 안정근)

## 🚦 안전
- 컷·착지 무릎 안쪽 말림 = 즉시 교정(평발 발목/무릎 부담).
- 점프는 **질 우선** — 발바닥 통증·발목 뻐근 시 중단, 셔플로 대체.
- 30분 배분 예시: 고정10 + 로테이션17 + 마무리3. 시간 없으면 컷·가속(플래그)/점프(배구)가 핵심.
