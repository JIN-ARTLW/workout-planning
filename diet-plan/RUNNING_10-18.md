# 🏃 러닝 플랜 — 10/18 10km 레이스

> 상위: `MASTER_PLAN.md`(감량) / `PHASE1_7-11_SPRINT.md`(7/11). 이 파일은 러닝 전용.
> 원칙: **감량기 = 보존, 9~10월 = 빌드.** 굶으며 퍼포먼스 향상 불가 → 55는 "근육 지키며" 도달해야 가벼움의 이득이 산다.

## 0. 목표 & 신체조건
- **레이스: 10/18 10km.** 1차 **sub-55(5'30"/km)** 현실 타겟 / 2차 **sub-50(5'00"/km)** 스트레치(9월 빌드 완벽+부상0 시 도전권).
- 현재 예상 ~1:06(6'36"/km). PB 58분(@~65kg, 잘 먹던 시기) → **55 + 잘 먹으며 훈련 시 PB 유력.**
- **장기 유지 체중 = ~55**(50은 회복력·골밀도 부담, 55가 스윗스팟). 가벼움 = 발목·족저근막 부하↓ = 부상 보호.
- ⚠️ **부상 이력/리스크: 왼발목(현재 괜찮으나 약간 뻣뻣) + 유연성 평발(오버프로네이션) → 족저근막염·발목 고위험.** 부상 관리 = 1순위.

## 1. 🦶 발·발목 프리햅 (평발+발목 — 비협상, 매일/러닝 전후)
- **신발/인솔:** 안정화(스터빌리티) 러닝화 or **아치 서포트 인솔** 필수. 오버프로네이션 교정 = 족저근막·발목 부하↓. (러닝화 마모 600~800km마다 교체)
- **AM 루틴 유지:** 발목·균형·래더 10분(이미 하는 것 — 평발/발목에 최적, 절대 누락 X).
- **강화(주 3~4회):** 이심성 카프(하강 3초) / 타월 스크런치(발가락으로 수건 끌기) / short-foot(아치 들기) / 한발 밸런스 30초 / 티비알리스(발끝 들기).
- **유연성(러닝 후):** 종아리·소레우스 스트레칭, 족저근막 볼 롤링, 발목 도르시플렉션.
- **로드 관리:** 주간 거리 **+10% 이내**만 증가. 갑작스런 마일리지·스피드 점프 = 평발 부상 트리거.
- 🚨 **즉시 감속 신호:** 아침 첫 발디딤 발바닥 통증(족저근막염 초기) / 발목 붓기·통증 / 정강이 통증. → 하루이틀 쉬고 걷기 대체, 무리 금지.

## 3. 감량기 러닝 디테일 (지금 — kotcha 보정)
- kotcha는 풀연료 기준 프로그램이라 **감량 중엔 막판 스피드 램프(속도 13 등) 빼고** 이지로 마무리.
- 주간: 이지런 3~4회(속도 7~8, 7'30~8'30/km, 대화 가능) + 주말 약간 긴 이지(50분).
- 케이던스 167spm → **175 지향**(보폭 줄이고 빠른 발놀림 = 평발 충격↓).
- **하체 웨이트와 퀄리티 러닝 같은 날 겹치면 러닝 질↓** → 감량기엔 OK, 9월 빌드기엔 분리 or 러닝 먼저.

## 4. 빌드기(9월) 주간 템플릿 (예시 — 9월 들어 확정)
- 월: 이지 40분 + 하체
- 화: **인터벌**(예: 1km×4 @5'00, 조깅 회복) — 발목 OK 확인 후
- 수: 이지 30분 + 상체
- 목: **템포** 20~25분 @5'40~6'00
- 금: 휴식 or 모빌리티
- 토: **롱런** 8→12km 점증(이지)
- 일: 가벼운 조깅 or 크로스(자전거)
